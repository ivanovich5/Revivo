# Contribuir

Describe el problema y cómo reproducirlo con datos sintéticos. No publiques documentos personales ni imágenes de USB reales. Las pruebas de recuperación deben usar imágenes generadas; cualquier escritura física o formateo requiere revisión explícita.

Mantén la lectura de la fuente separada del destino. No elimines controles de identidad, de espacio, de rutas ni confirmaciones de borrado para simplificar la interfaz. Documenta límites y pruebas de cada cambio.

Las contribuciones de código propio deben ser compatibles con AGPL-3.0-only; documenta la licencia y procedencia de recursos nuevos.
